# Outfit GLBs (MakeHuman / MPFB clothes)

License: **CC0**. Per-asset author / licence / source records: `licenses/*.json`.
Repository-wide summary: `LICENSE_ASSETS.md`.

Each `*.glb` is a skinned export (GameEngine rig) of:
- MH basemesh body + young lightskinned diffuse
- One or more Clothes-type MHCLO assets, in equip order (see `garments` in `catalog.json`)

Masks, helmets and weapons are Clothes-type MHCLO assets too, so a sword is equipped through
the same call as a suit and comes out skinned to the hand.

Source folders:
- `tools/vendor/makehuman_system_assets/clothes/` (system assets)
- `tools/vendor/mpfb_user_data/data/clothes/` (community packs, fetched by
  `tools/download_mh_clothes_packs.py` — CC0 only, verified per asset)

Generated by: `tools/blender_export_mpfb_outfits.py` / `tools/export_mpfb_outfits.bat`

Texture pipeline, in order, after an export:
1. `python tools/shrink_outfit_textures.py` — diffuse to 1024, normals to 512
2. Godot import — extracts each embedded texture to a sibling PNG with its own `.import`
3. `python tools/externalize_glb_images.py` — GLB references those PNGs by uri, drops the
   embedded duplicate
4. `python tools/dedupe_outfit_textures.py` — byte-identical textures collapse into one
   `shared_*.png`, so an outfit no longer carries its own copy of the skin sheet

Files named `shared_*.png` are referenced by several outfits. Do not rename them by hand; step 4
rewrites the GLB uris that point at them.

Catalog: `catalog.json`
